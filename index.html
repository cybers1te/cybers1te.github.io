En savoir plus

GitHub Pages n'héberge que des fichiers statiques : il ne peut exécuter ni serveur ni base de données. Cette version de Trueware fonctionne donc entièrement dans votre navigateur — rien n'est envoyé nulle part, et les données ne sont visibles que sur cet appareil. Les mots de passe sont dérivés par PBKDF2 avant d'être stockés, mais un compte local ne protège rien : n'y mettez pas un mot de passe que vous utilisez ailleurs. La version serveur complète (Flask + SQLite, avec sessions, protection CSRF et administration) est dans le dossier trueware/ du dépôt.
